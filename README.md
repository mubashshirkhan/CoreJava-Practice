# ☕ Core Java Practice

A structured collection of my **Core Java practice programs, concepts, examples, and exercises** created while learning Java from the fundamentals to advanced Core Java topics.

This repository is part of my journey toward becoming a **Full Stack Java Developer (FSJD)**.

---

## 🎯 Purpose

The main goal of this repository is to:

* Build a strong foundation in Core Java
* Practice Java syntax and programming concepts
* Understand Object-Oriented Programming
* Improve problem-solving and logical thinking
* Practice writing clean and readable Java code
* Track my progress chapter by chapter
* Maintain a reference for Java concepts and examples

### 1. 🔹 Basics

Fundamental Java concepts and beginner-level programs.

* Java syntax
* Variables
* Data types
* Operators
* Input and output
* Type casting
* Expressions
* Basic programs
* String basics

Programs for understanding how Java code executes.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/mubashshirkhan/CoreJava-Practice.git
```

### 2. Navigate to the project

```bash
cd CoreJava-Practice
```

### 3. Compile a Java program

```bash
javac FileName.java
```

### 4. Run the program

```bash
java FileName
```
