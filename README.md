# Core Java Practice

This repository contains hands-on Core Java practice programs, grouped by topic.  
It is a personal learning workspace for building strong Java fundamentals through small, focused examples.

## Topics in this repository

- `basics` – Java syntax, data types, variables, operators, simple programs
- `Blocks` – static, instance, and local block behavior
- `class` – classes, objects, fields, constructors, and object usage
- `excutionflow` – conditionals, loops, and execution flow examples
- `methods` – method declaration, parameters, return types, overloading
- `StringMethods` – String and StringBuilder operations
- `OOP Principles` – inheritance, encapsulation, polymorphism examples
- `Interface` – interface-based design and usage examples
- `exception handling` – custom exceptions and handling patterns
- `Multithreading` – thread lifecycle, synchronization, wait/notify, deadlock demos

> Note: Some folder names intentionally keep their original naming (for example, `excutionflow`).

## Requirements

- Java JDK (17+ recommended)
- Any Java IDE/editor (IntelliJ IDEA, Eclipse, VS Code, etc.)

## How to run examples

1. Clone the repository:

   ```bash
   git clone https://github.com/mubashshirkhan/CoreJava-Practice.git
   cd CoreJava-Practice
   ```

2. Move to the folder containing the file you want to run, then compile and run:

   ```bash
   javac FileName.java
   java FileName
   ```
